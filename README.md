# تمام شوب — TAMAM SHOP

متجر إلكتروني للطلب المباشر والدفع عند الاستلام، يبيع للعراق ودول الخليج (السعودية، الكويت، الإمارات، قطر، البحرين، عُمان).
كل منتج إله دولة وعملة تختارها من لوحة التحكم، وصفحة المنتج تتغير حسب دولته: العملة، التوصيل، صيغة رقم الهاتف، قائمة المحافظات/المدن، والعنوان الوطني للسعودية.

- **المتجر**: `/` الرئيسية، `/product/رقم` صفحة هبوط لكل منتج، `/success` صفحة الشكر
- **لوحة التحكم**: `/admin` (المنتجات، الطلبات، الدول والتوصيل، الإعدادات)
- **الطلب يروح إلى**: لوحة التحكم + شيت 1 أو شيت 2 (حسب المنتج) + تلغرام + ميتا وتيك توك (إذا مفعّلة)

مبني بـ React 19 + Vite، صفحات تنرسم بالسيرفر (SSR) على Netlify Functions، وقاعدة البيانات والصور على Supabase.

## خطوات الرفع (مرة وحدة)

### 1) Supabase — قاعدة البيانات والصور
1. ادخل [supabase.com](https://supabase.com) ← **New project** (اختار أقرب منطقة، مثلاً Frankfurt).
2. افتح **SQL Editor** ← **New query** ← الصق ملف `supabase/setup.sql` كامل ← **Run**.
   (آمن تشغله أكثر من مرة، ما يمسح بياناتك.)
3. من **Project Settings ← API** انسخ:
   - **Project URL** ← هذا `SUPABASE_URL`
   - **service_role** أو **secret key** ← هذا `SUPABASE_SERVICE_ROLE_KEY` (لا تشاركه مع أحد)

### 2) GitHub — الكود
1. ادخل [github.com](https://github.com) ← **New repository** ← خلّيه **Private** ← Create.
2. اضغط **uploading an existing file** واسحب كل ملفات هذا المجلد (بدون `node_modules` و `dist` و `.env`) ← **Commit changes**.

### 3) Netlify — الموقع
1. ادخل [app.netlify.com](https://app.netlify.com) ← **Add new site ← Import an existing project ← GitHub** ← اختار المستودع.
2. الإعدادات تتعبى تلقائياً من `netlify.toml` (Build: `npm run build`، Publish: `dist/client`). اضغط **Deploy**.
3. روح **Site configuration ← Environment variables** وضيف المتغيرات (الجدول تحت).
4. بعد إضافتها: **Deploys ← Trigger deploy ← Deploy site**.

### 4) الشيتات (شيت 1 وشيت 2)
لكل شيت:
1. افتح Google Sheet جديد ← **Extensions ← Apps Script**.
2. امسح الموجود والصق `supabase/sheet-apps-script.js` ← **Save**.
3. **Deploy ← New deployment** ← النوع **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. **Deploy** ← وافق على الصلاحيات ← انسخ رابط **Web app** (ينتهي بـ `/exec`).
5. حطه بـ Netlify: `GOOGLE_SHEET_1_URL` للأول و `GOOGLE_SHEET_2_URL` للثاني، وسوّي Deploy من جديد.

أعمدة الشيت: اسم المنتج · اسم المستلم · الرقم · الدولة · المحافظة / المدينة · العنوان · العنوان الوطني · معرف المنتج · الكمية · السعر الكلي · العملة · الملاحظات · التاريخ · رقم الطلب.

### 5) التجربة
1. افتح `موقعك/admin` وادخل بكلمة السر.
2. **الإعدادات**: تأكد كل شي مضبوط (علامة ✓).
3. **إضافة منتج**: اختار الدولة، اكتب الاسم والسعر، ارفع الصور، اختار شيت 1 أو 2 ← نشر.
4. افتح المنتج بالمتجر وسوّي طلب تجريبي، وتأكد إنه وصل للوحة التحكم وللشيت ولتلغرام.

## متغيرات Netlify

| المتغير | شنو هو | إلزامي؟ |
|---|---|---|
| `SUPABASE_URL` | رابط مشروع Supabase | نعم |
| `SUPABASE_SERVICE_ROLE_KEY` | المفتاح السري لـ Supabase | نعم |
| `ADMIN_PASSWORD` | كلمة سر `/admin` (10 أحرف أو أكثر) | نعم |
| `APP_URL` | رابط موقعك النهائي | نعم |
| `GOOGLE_SHEET_1_URL` | رابط سكربت شيت 1 | نعم إذا عندك منتجات على شيت 1 |
| `GOOGLE_SHEET_2_URL` | رابط سكربت شيت 2 | نعم إذا عندك منتجات على شيت 2 |
| `SHEET_1_NAME` / `SHEET_2_NAME` | اسم يظهر بلوحة التحكم وتلغرام | اختياري |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | إشعار فوري بكل طلب | اختياري |
| `WHATSAPP_NUMBER` | زر واتساب بالموقع (مثال `+9647700000000`) | اختياري |
| `META_PIXEL_ID` | بيكسل ميتا | اختياري |
| `META_ACCESS_TOKEN` | ميتا من السيرفر (Conversions API) | اختياري |
| `TIKTOK_PIXEL_ID` / `TIKTOK_ACCESS_TOKEN` | تيك توك | اختياري |
| `IQD_TO_USD_RATE` | سعر صرف الدينار للدولار (افتراضي 1400) | اختياري |
| `NETLIFY_PURGE_API_TOKEN` + `TAMAM_SITE_ID` | يخلي تعديلات لوحة التحكم تبين فوراً | اختياري |

بدون `NETLIFY_PURGE_API_TOKEN` أي تعديل (سعر، صورة، توصيل) يبين بالموقع خلال دقيقة تقريباً.
مثال كامل بملف `env.example`.

> إذا جنت تستخدم المشروع القديم: `GOOGLE_SHEET_WEBHOOK_URL` ينقرأ كشيت 1 و `GOOGLE_SHEET_WEBHOOK_URL_MANUAL` كشيت 2 إذا ما حطيت المتغيرات الجديدة.

## لوحة التحكم

- **المنتجات**: إضافة، تعديل، إخفاء، حذف. كل منتج: الدولة والعملة، السعر والسعر قبل الخصم، القسم، الوصف، المميزات، الصور (أول صورة هي الرئيسية)، المخزون (فارغ = بدون حد)، وشيت 1 أو 2.
- **الطلبات**: كل الطلبات بعملة دولتها، وتغيير الحالة (جديد، مؤكد، قيد التوصيل، تم التسليم، ملغي).
- **الدول والتوصيل**: تشغيل/إيقاف دولة، توصيل مجاني أو بسعر، مجاني فوق مبلغ، مدة التوصيل، نص الشريط العلوي، والعنوان الوطني للسعودية.
- **الإعدادات**: تبين أي متغير مضبوط وأيهم ناقص.

## التشغيل على جهازك (للمطورين)

```bash
npm install
cp env.example .env    # واملأ القيم
npm run dev            # http://localhost:3000  و  /admin
```

بنية المشروع:

```
src/            واجهة المتجر (React) + منطق الدول والعملات (src/lib/countries.ts)
server/         قاعدة البيانات، الطلبات، ميتا، تيك توك، الكاش (تشتغل بالسيرفر فقط)
netlify/        دوال Netlify (الصفحات، الطلب، لوحة التحكم...)
public/admin.html   لوحة التحكم
supabase/       setup.sql + سكربت الشيت
```
